🚀 AI Resume Analyzer – Built with AI Assistance (Gemini API)

This project is an AI-powered Resume Analyzer that evaluates resume text, provides a score, and gives improvement suggestions using the Google Gemini API.

The project structure, code generation, and API integration were assisted by AI tools, while the concept, UX flow, design decisions, API configuration, testing, and deployment were completed by me.

This project demonstrates AI-assisted development, modern frontend workflow, and the ability to build functional applications using LLM APIs.

💡 About This Project

This tool helps job seekers improve their resumes by giving:

Score (0–100)

Skill gaps

Formatting suggestions

Keyword recommendations

Overall resume strength

You paste or upload resume text → AI analyzes → result displayed instantly.

✨ Features

📝 Paste or upload resume text

⚡ Real-time analysis using Gemini API

📊 Resume scoring

🔍 Skill and keyword extraction

📌 Improvement suggestions

🎨 Clean, responsive UI (TailwindCSS)

🚀 Fast deployment on Vercel
